Snap Desk（也写作 SnapDesk）是一款免费开源的跨平台桌面工具：区域截图、滚动截图、图片标注、桌面贴图、MP4/GIF 录屏、OCR 文字识别、文本翻译与剪贴板历史管理。

主要功能

从截下一张图到把它用出去，中间的每一步都在同一个应用里。

截图与标注

区域、全屏与窗口截图；箭头、文字、马赛克、模糊、序号等标注工具，支持 PNG、JPEG、WebP 导出。

滚动截图

手动纵向或横向滚动、自动拼接与实时预览，可导出长 PNG 图片。

桌面贴图

将截图、图片或剪贴板内容固定在桌面，支持置顶、透明度、缩放与继续标注。

录屏

录制区域或显示器为 MP4 / GIF，支持暂停恢复、实时标注和键鼠显示；MP4 可录制系统音频及麦克风。

识别与翻译

可选择 PaddleOCR、Windows OCR 等离线引擎，或自行配置在线识别及翻译 API。

剪贴板历史

保存文本、图片与文件路径历史，提供分类、搜索、收藏、预览与导出。

下载与平台

Windows 版功能完整；macOS 与 Linux 为预览版，功能正在逐步适配。
