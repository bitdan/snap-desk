截图、滚动截图、录屏与 OCR，集中在 Snap Desk

Snap Desk（也写作 SnapDesk）是一款免费开源的 Windows 桌面工具：区域截图、滚动截图、图片标注、桌面贴图、MP4/GIF 录屏、OCR 文字识别、文本翻译与剪贴板历史管理。

主要功能

截图与图片标注

区域、全屏与窗口截图；箭头、文字、马赛克、模糊、序号等标注工具，支持 PNG、JPEG、WebP 导出。

滚动截图

手动纵向或横向滚动、自动拼接与实时预览，可导出长 PNG 图片。

桌面贴图

将截图、图片或剪贴板内容固定在桌面，支持置顶、透明度、缩放与继续标注。

录屏 MP4 / GIF

录制区域或显示器，支持暂停恢复、实时标注和键鼠显示；MP4 可录制系统音频及麦克风。

OCR 文字识别与翻译

可选择 PaddleOCR、Windows OCR 等离线引擎，或自行配置在线识别及翻译 API。

剪贴板历史管理

保存文本、图片与文件路径历史，提供分类、搜索、收藏、预览与导出。

下载与开始使用

从 GitHub Releases 下载安装包或独立 EXE。截图、标注与录屏可在本机运行；离线 OCR 或翻译引擎需要在应用内按需安装相关资源。可选在线服务需由用户配置 API Key。

隐私提示：选择在线 OCR 时会向所选服务上传图片，在线翻译会发送待翻译文字；费用及额度由对应服务商决定。
