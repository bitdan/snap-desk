Screenshot, scrolling capture, screen recording & OCR in one Windows app

Snap Desk is a free and open-source Windows desktop utility for screenshots, scrolling capture, annotation, image pinning, MP4/GIF recording, OCR, translation, and clipboard history.

Features

Screenshots & annotations

Capture regions, screens, or windows. Add arrows, text, numbered labels, blur, and mosaic; export PNG, JPEG, or WebP.

Scrolling screenshots

Stitch manually scrolled vertical or horizontal content, preview captures, and export long PNG images.

Desktop image pinning

Keep screenshots, images, or clipboard content on top of your desktop; adjust opacity, zoom, or annotations.

MP4 / GIF screen recording

Record a screen or region with pause/resume, live annotations, and input visualization. MP4 supports system and microphone audio.

OCR & translation

Choose offline OCR engines such as PaddleOCR or Windows OCR, or configure optional online recognition and translation APIs.

Clipboard history

Find text, images, and file paths with categories, search, favorites, preview, and export options.

Download & getting started

Get the installer or standalone EXE from GitHub Releases. Screenshots, annotations, and recording work locally. Install optional offline OCR or translation resources in the app as needed, or configure your own API keys for online services.

Privacy: online OCR sends the selected image to your chosen provider; online translation sends text. Pricing and quotas are determined by the provider.
