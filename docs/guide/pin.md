## 创建贴图 {#create}

| 来源 | 方式 |
| --- | --- |
| 截图 | 截图时按 <kbd>F2</kbd>，或点工具栏的“贴图”按钮 |
| 剪贴板 | 不在截图时按 <kbd>F2</kbd>，把剪贴板里的图片、文字或颜色贴出来 |
| 剪贴板历史 | 卡片上的贴图按钮；多选后点底栏“悬浮贴图”，每条各贴一张 |
| 暂存架 | 卡片上的“取下为贴图” |
| 图片文件 | 主界面“贴图”页的“打开图片贴图”，支持 PNG / JPEG / WebP |

文字会排版成一张图片贴出来，适合把一段说明、一串地址放在手边。

## 移动、缩放与关闭 {#basic}

- **拖动**贴图可以移动位置；
- **滚轮**或 <kbd>+</kbd> / <kbd>-</kbd> 放大缩小；
- <kbd>Esc</kbd> 或 <kbd>Ctrl</kbd>+<kbd>W</kbd> 关闭当前贴图；
- <kbd>Ctrl</kbd>+<kbd>C</kbd> 复制图片，<kbd>Ctrl</kbd>+<kbd>S</kbd> 保存为文件；
- **按住 <kbd>Ctrl</kbd>（macOS 为 <kbd>⌥ Option</kbd>）再拖动**，可以把贴图拖进聊天窗口、文档或文件夹：文字贴图拖出的是文字，其余拖出的是带标注的 PNG。

## 工具栏 {#toolbar}

按 <kbd>Space</kbd> 显示或隐藏贴图下方的工具栏。工具栏是一行胶囊按钮，包括：

- **标注**：和截图里一样的标注工具，可以在贴图上继续画；
- **图像调整**：旋转、翻转、灰度、反色、自动调整；
- **识别**：识别文字、识别二维码、翻译图片。

## 右键菜单 {#menu}

在贴图上单击右键，可以找到全部操作：

| 菜单项 | 说明 |
| --- | --- |
| 窗口置顶 | 始终显示在其他窗口上方 |
| 锁定贴图 | 防止误拖动、误缩放和误标注 |
| 鼠标穿透 | 鼠标点击穿过贴图，直接操作下面的窗口（<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>P</kbd>） |
| 不透明度 | 让贴图半透明，方便对齐下层内容 |
| 显示工具栏 | 同 <kbd>Space</kbd> |
| 清空标注 | 去掉贴图上画的所有标注 |
| 复制 / 保存图片 | 同 <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Ctrl</kbd>+<kbd>S</kbd> |
| 关闭贴图 | 同 <kbd>Esc</kbd> |

> **开了鼠标穿透后点不到贴图了？** 再按一次 <kbd>F2</kbd>：有穿透中的贴图时，<kbd>F2</kbd> 会先把它们恢复成可点击的状态。
{: .note}

## 统一外观 {#style}

在主界面的“贴图”页可以统一设置所有贴图的阴影、圆角和边框，也可以按分组管理多张贴图。
