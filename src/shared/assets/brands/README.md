图标仅用于在“服务管理”中标识对应的服务商；商标归各自所有者，使用时遵守各服务商的品牌规范。

| 文件 | 用于 |
| --- | --- |
| openai.svg | OpenAI 兼容接口 |
| deepseek-color.svg | DeepSeek |
| groq.svg | Groq / Groq Vision |
| deepl-color.svg | DeepL |
| microsoft-color.svg | Windows OCR |
| ollama.svg | 本机兼容服务 |
| baidu-color.svg | PaddleOCR / Paddle API |

没有对应图标的服务（OCR.space、WeChat OCR、CTranslate2、自定义接口）继续使用字母图标。
